Service notes

Important behaviour to understand before deploying publicly.

• Jobs run on the server, not in the browser.
• Server restarts may interrupt active jobs.
• Persistent storage must be configured on the host.
• Use only content you own or are allowed to download.
• Set APP_PASSWORD before public deployment.
